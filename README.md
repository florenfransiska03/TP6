apa itu javascript dan kegunaannya
javascript adalah bahasa pemrograman yang berbasis pada prototipe dan bersifat dinamis yang berarti kodenya dapat berubah-ubah selama masa eksekusi. Javascript juga merupakan bahasa yang tidak perlu dikompilasi, yang memudahkan pengembang untuk langsung bisa melihat hasil dari kode yang tulis. javascript digunakan untuk membuat website interaktif, mengelolah dan menampilkan data, membuat aplikasi web dan membuat backend.

apa itu jQuery dan kegunaannya
jQuery adalah library javascript yang bisa mempermudah kita untuk menulis kode javaScript terutama untuk memanipulasi elemen HTML, menangani klik, membuat animasi dan mengambil data dari server. kegunaan untuk menangani aksi pengguna, memanipulasi HTML dan membuat efek animasi.

jelaskan perbedaan javascript dan jquery
Javascript adalah bahasa pemrogramannya sedangkan jQuery merupakan library yang dibuat menggunakan javascript untuk mempermudah pekerjaan. javascript digunakan untuk membuat logika sedangkan jquery untuk mempermudah manipulasi HTML
